# NexusDB — an accessory brain for any AI model

A portable cartridge that gives any AI model — open or closed, small or large — a company's knowledge, procedures and ways of working, cites its sources and keeps learning from use. **No retraining of the model.**

*By [X Quantum Tech](https://xquantumtech.com/it/nexusdb). Not the NexusDB database for Delphi (nexusdb.com). “NexusDB” is a working name.*

## Measured, November 2026

| | Result |
|---|---|
| **LongMemEval** (public benchmark, official judge) | **85.6%** with GPT-4o — Mastra 84.2%, Supermemory 81.6%, Zep 71.2% as published · [every answer public](https://xquantumtech.com/benchmark/longmemeval/) |
| **Small vs frontier** | a 4B model with the cartridge and our search: 69.6% vs 68.6–71.0% for four frontier models |
| **vs fine-tuning** | +32.6 points with the cartridge vs +8.9 with fine-tuning, same model, zero training |
| **Learning from use** | +11.2 points on never-seen wordings, damage on untouched topics −0.4 (3 seeds) |
| **Procedures** | next step found among the first 3 results: 2.6% → 50.5% after one verified run |
